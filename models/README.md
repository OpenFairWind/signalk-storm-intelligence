# Pretrained models

`stormfusion-reference-v1.json` is the bundled deterministic reference DNN. See `docs/model-card-stormfusion-reference-v1.md` and `docs/multimodal-dnn.md`.

External operational/research models should normally be stored outside the npm package and selected using the `multimodal-dnn.modelPath` setting. Model provenance, feature schema, licence and validation domain must be documented.
